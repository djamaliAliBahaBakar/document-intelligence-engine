# Label Studio data

Ce répertoire contient les artefacts locaux liés à l'annotation :

- tâches Label Studio ;
- médias ;
- exports d'annotations ;
- fusion des annotations.

Ces fichiers ne sont pas versionnés dans Git en raison de leur taille et de leur caractère local.

Le fichier `export/annotations_all.json` est utilisé par le pipeline de préparation pour construire le dataset LayoutLM.
