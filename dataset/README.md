# Dataset

Ce répertoire contient les données locales utilisées pour l'entraînement et l'évaluation des modèles.

- `raw/` : PDF sources
- `images/` : pages converties en images
- `ocr/` : sorties OCR Tesseract
- `processed/` : datasets préparés pour LayoutLMv3 et LiLT

Les données ne sont pas versionnées dans Git en raison de leur taille et de leur caractère privés (devis entreprises).
